# DigitalMakery offering

- Digitizing processes and automating them as far as possible
- Helping in situations where no-code and low-code tools reach their limit
  - Example: Connecting tools that don't offer programmatic access through APIs, e.g. using [stagehand](https://github.com/browserbase/stagehand)
- Custom business solutions to automation problems using
  - custom code
  - ai agents
  - ai harnesses & claws
  - context engineering
  - innovative db solutions like graphs
- Building prototypes to test and validate ideas facing
  - internal users
  - external customers
- Using AI when it makes sense that is when there are too many paths than it is possible to codeify. Otherwise attempt to use deterministic solutions as much as possible

## What DigitalMakery is NOT offering

- No-code, low-code automations using tools like Make and Zapier
- Selling AI for the sake of ai.
- Throwaway ai slop software
- Setting up off-the-shelve-solutions like Microsoft 365 or Google Workspace. My [ideal customer](./icp.md) will have already set that up
